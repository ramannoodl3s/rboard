Six themes share one set of token names, each taken from a reference sleeve and faded to a dusty, low-chroma version: Carbon (black), Teal Room, Handset and Albumen (dark), Pictogram and Blood Orange (light). This sheet shows the same mini board in each.

**Consumer provides:** `data-theme="<id>"` on the app root, with the id one of `carbon`, `nova`, `handset`, `albumen`, `pictogram`, `survivor`.

- Switching theme changes token values only. Layout, radii, type and icons stay identical.
- `canvas` stays low-saturation in every theme so board images keep their own colour; the sleeve's hue shows up most in panels and the accent.
- Carbon is the default. The theme picker lists themes by name in `label` style, each with a 3-swatch preview of `canvas`, `surface-raised` and `accent`.
